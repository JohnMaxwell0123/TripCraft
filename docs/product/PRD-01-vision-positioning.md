# PRD-01 · 愿景、定位与能力边界

## 1. 产品定位与核心愿景

- **一句话定位**：统一账号、多端协同的智能旅行路书 App，以免安装单文件离线快照作为一等交付形态。
- **核心愿景**：为自驾与深度游旅客提供行前启发式共创、行中可靠协同、行后资产沉淀的完整数字化体验；同时作为地接社与定制车队的数字化外骨骼，赋能专业线下从业者实现高人效、高质感、带品牌资产的交付。

## 2. 行业痛点与现状替代方案

基于 [白皮书 §1 与 §2.1](../WHITEPAPER.md#一tripcraft-要解决什么问题)，当前旅行规划与行中交付存在结构性断裂：

| 场景阶段 | 现有替代方案 | 真实体验缺陷与局限 | TripCraft 破局点 |
| :--- | :--- | :--- | :--- |
| **行前规划** | 社交平台攻略笔记 + 手工 Excel/Word | 零散信息搜集耗时 4–8 小时；同行人诉求难以结构化汇总；缺乏可行性与开闭馆校验。 | 启发式向导对话澄清，自动对齐硬约束；同行人结构化提名且保护个人隐私。 |
| **行中交付** | 静态 PDF / 聊天记录长图 / 口头交代 | 无法自适应多端设备；断网与弱网易失效；行程突发变更时各成员步调脱节。 | 离线优先架构；零依赖单文件高保真快照；点对点增量补丁（TripPatch）秒级分发。 |
| **座舱体验** | 手机支架看导航 + 副驾人肉播报 | 低头看手机引发安全隐患；普通导航缺乏沿途深度人文展卡与物资补给预警。 | 系统级深链一键向车机下发全天途经点；车载大屏与副驾屏自适应展卡联动。 |
| **B 端服务** | 通用办公软件手写行程单 | 定制师单份路书耗时过长；缺乏自有数字化品牌；行后照片散落无法沉淀复购。 | B 端白标工作台；特许资源库复用；自动化行后回忆录与专属管家直连通道。 |

## 3. 核心价值主张 (Value Proposition)

- **C 端旅客**：让每一次自驾出行都拥有一位懂约束、能容灾、懂同行人偏好的随车数字领队。
- **B 端机构（地接社 / 车队）**：让专业定制师在 20 分钟内产出带企业品牌、支持座舱投递与断网容灾的旗舰级交互路书。

## 5. 能力边界规范 (Scope & Boundaries)

| 业务/技术领域 | 我们做（In Scope） | 我们不做（Out of Scope） | 依赖第三方/外部条件 | 对应依据与勘误链接 |
| :--- | :--- | :--- | :--- | :--- |
| **导航引导** | 节点规划、游玩节奏建议、深链投递经纬度 | 不自研底层导航引擎、不提供逐转向实时语音导航 | 依赖系统已安装的高德地图/百度地图 App | [ERRATA 勘误 1](../ERRATA.md#勘误-1-彻底纠正车厂技术栈夸大叙事与不实声称) ｜ [07 §7.1](../07-legal-and-compliance.md#71-三条责任边界线的法律落地) |
| **智能驾驶 (NOA)** | 标注道路类型、路况风险与通行注意事项 | 不接入车辆底层 CAN 总线、不触发或干预 NOA 领航辅助 | 车辆辅助驾驶由车机系统原生算法控制 | [ERRATA 勘误 1](../ERRATA.md#勘误-1-彻底纠正车厂技术栈夸大叙事与不实声称) ｜ [02 §2.0](../02-cockpit-protocol.md) |

| **能耗与 SOC** | 沿途充电站与加油站预警规划、距离测算 | 不读取车辆电池实时 SOC 电量、不动态计算电化学续航衰减 | 用户手动选择车辆动力类型或设定补能阈值 | [ERRATA 勘误 1](../ERRATA.md#勘误-1-彻底纠正车厂技术栈夸大叙事与不实声称) ｜ [02 §2.7](../02-cockpit-protocol.md#27-自驾全要素适配新能源能耗海拔与极端气候) |

## 6. 明确非目标 (Non-Goals)

1. **不自研地图导航底座**：不承担图商资质成本与测绘合规风险，聚焦上层行程逻辑与叙事排程。
2. **不自建旅游交易电商平台**：绝不触碰无证经营旅行社及资金沉淀监管红线。
3. **现阶段不做车机原生 App**：避免针对各车厂封闭车机系统做高成本适配与资质申请。
4. **不承诺接管或控制车辆硬件**：所有行程信息仅作为行车参考，安全责任严格归属于驾驶员。

## 7. 成功度量标准

与 [PRD-05 商业模式](PRD-05-business-model.md#5-指标体系建议北极星与核心运营指标) 对齐：
- **C 端指标**：离线单文件导出率、多端同步激活率、旅后回忆录生成转化率。
- **B 端指标**：试点机构月度路书制作量、定制师路书平均编辑耗时（从 4 小时压降至 20 分钟内）、客户交付满意度 NPS。
