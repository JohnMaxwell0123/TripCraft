# 第 9 章 · 视觉设计系统

> **本章性质**：设计语言规格，**不涉及技术实现**。
> **回答的问题**：TripCraft 长什么样？为什么长这样？
> **上游冲突**：README §4.1 定义了「五大主题」，§5.2 定义了「五大设计流派」，**但从未说明二者如何组合**。本章 §9.1 解决这个问题。
> **状态**：`Design Spec`

## 9.1 ★ 先解决一个结构性矛盾：主题与流派的关系

### 9.1.1 矛盾是什么

README 里同时存在两套「五个」：

| 出处 | 名称 | 性质 |
| :--- | :--- | :--- |
| §4.1 | 五大液态玻璃**主题**：敦煌金 / 赛博蓝 / 高原青 / 江南翠 / 冰川银 | 由**目的地**自动触发 |
| §5.2 | 五大设计**流派**：Apple / Material You / 复古拟物 / 瑞士极简 / 赛博 HUD | 由**用户**主动选择，VIP 专属 |

**问题**：用户选了「赛博朋克 HUD」流派，又去了江南，自动触发「江南翠」主题 —— **出来是个什么？**

**如果不管，就会出现「霓虹绿的青苔色」这种四不像。** 而且用户是在生成之后才发现的。

### 9.1.2 解法：它们回答的是两个不同的问题

| | 主题 | 流派 |
| :--- | :--- | :--- |
| **回答** | 这是**哪里** | 你**怎么看待**这次旅行 |
| **来源** | 客观（目的地经纬度） | 主观（审美取向） |
| **谁定** | 系统自动 | 用户选择 |
| **比喻** | 旅途的**光线** | 相机的**镜头** |
| **变化** | 换目的地就换 | 选定后不变 |

> 📌 **一句话：流派定「形」，主题定「色」。**
>
> 流派决定**结构、材质、排版、动效**；主题决定**色彩与意象**。
>
> **它们是正交的，但不是完全自由组合的。**

### 9.1.3 兼容性矩阵（★ 本节的核心产出）

**不是每个主题都能配每个流派。** 产品必须**提前拦住**，而不是让用户生成一个四不像再后悔。

| 流派 ↓ / 主题 → | 敦煌金 | 赛博蓝 | 高原青 | 江南翠 | 冰川银 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Apple 液态玻璃** | ✅ | ✅ | ✅ | ✅ | ✅ |
| **Material You 流光** | ✅ | ✅ | ✅ | ✅ | ✅ |
| **复古拟物手账** | ✅★ | ⬜ | ⬜ | ✅ | ⬜ |
| **瑞士国际主义** | ✅ | ✅ | ✅ | ✅ | ✅ |
| **赛博夜巡 HUD** | ⬜ | ✅★ | ⬜ | ⬜ | ✅ |

**图例**：✅ 自然 ｜ ✅★ 最佳搭配 ｜ ⬜ 不兼容

**不兼容的原因（必须能说清，否则会变成随意的限制）**：

| 组合 | 为什么不行 |
| :--- | :--- |
| 复古拟物 × 赛博蓝 | 拟物要求「**物质感**」——牛皮纸、黄铜、火漆。霓虹蓝是**光**，不是**物**。纸上印不出霓虹 |
| 复古拟物 × 高原青 | 同上，且高原青的意象是「稀薄通透」，与拟物的「厚重实体」相反 |
| 赛博 HUD × 敦煌金 | HUD 是**暗底发光**，敦煌金是**暖底沉光**。两者都要抢「光」这个通道 |
| 赛博 HUD × 高原青 | 同上；且高原青的冷是**自然的冷**，HUD 的冷是**人造的冷** |
| 赛博 HUD × 江南翠 | 同上；江南是湿润柔和的，HUD 是锐利硬边的 |

> ⚠️ **当用户选了不兼容的组合时，产品不能静默降级。**
>
> ```text
> 你选了「赛博夜巡」，但这次去的是江南。
> 赛博是暗底发光的，江南的绿色在暗底上会发灰，不好看。
>
> [ 换成瑞士极简 ]   [ 保持赛博，我知道会怎样 ]
> ```
>
> **给推荐 + 说明理由 + 保留否决权** —— 与 [§8.10 三段式](08-socratic-interaction-design.md#810-专业意见的表达方式)同一条原则。

### 9.1.4 免费版与 VIP 版的边界

| | 免费版 | VIP 版 |
| :--- | :--- | :--- |
| **主题** | 全套 5 个，自动匹配 | 全套 5 个，**可手动覆盖** |
| **流派** | 固定 Apple 液态玻璃 | **5 个流派自由选择** |

> 📌 **这个边界是刻意的**：免费版**不阉割色彩**（主题是"这是哪里"，属于行程本身的一部分），**只在"形"上做区分**（流派是审美表达，属于增值）。
>
> 与 [白皮书 §5.1](WHITEPAPER.md#51-通用核心底座做大留存率与自发裂变)「绝不阉割核心自驾体验」一致。

## 9.2 五大主题的完整设计

### 9.2.1 主题的设计方法

**每套主题不是"挑几个好看的颜色"，而是从真实的地理与历史里提取一个「光的性格」。**

设计步骤（以敦煌金为例，其余同法）：

```text
① 找意象  →  莫高窟壁画、鸣沙山日落、汉代漆器
② 找光的性格  →  ★ 不是"金色"，是"氧化的金"
③ 定色彩  →  从意象里取色，不发明颜色
④ 定材质  →  这个光落在什么表面上
⑤ 定字体  →  什么字体配得上这种光
⑥ 定动效  →  这种光怎么变化
```

> 🔴 **第 ② 步是全部的关键。**
>
> 「敦煌金」如果做成**闪亮的金色**，出来就是**土豪金**——廉价、俗气、像暴发户的酒店大堂。
>
> 但**真实的敦煌壁画上的金箔，经过一千年已经氧化成了暖褐色**，它不闪耀，它**沉**。
>
> **同一个颜色词，两种理解，出来的东西差着一个档次。** 这个区别不在配色表里，在对意象的理解里。**这是设计，不是参数。**

### 9.2.2 敦煌金 `dunhuang-gold`

| 项 | 内容 |
| :--- | :--- |
| **触发** | 甘肃 · 青海 · 新疆 · 宁夏 · 丝路沿线 |
| **意象** | 莫高窟氧化金箔、鸣沙山落日、青金石颜料、汉代漆器 |
| **光的性格** | **沉，不是亮**。暖调的、有重量的、被时间磨过的光 |
| **气质词** | 厚重 · 苍茫 · 有年头 |

**配色**

| 角色 | 色值 | 来历 |
| :--- | :--- | :--- |
| 主色 | `#B8863B` | 氧化金箔——**饱和度刻意压低**，不用 `#FFD700` |
| 辅色 | `#1F4E79` | 青金石蓝——敦煌壁画里真实使用的进口颜料 |
| 底色 | `#F2E8D5` | 沙——偏黄的暖白，不是纯白 |
| 强调 | `#8C3A2B` | 赭石红——壁画底色 |
| 文字 | `#3A2E1F` | 暖褐黑——不用纯黑 |

> ⚠️ **「不用纯黑」是一条通用规则**（五个主题都适用）。纯黑 `#000` 在暖色底上会显得刺眼且廉价，**用暖褐黑**。
>
> 这条规则还带来一个副作用：**纯黑文字在 OLED 屏上滚动时会有拖影**，暖褐黑则不会。**设计决策顺带解决了一个体验问题。**

**材质与字体**

| 项 | 设计 |
| :--- | :--- |
| 材质 | 磨砂砂岩（哑光，**无高光反射**）、亚麻纸（极淡的织物纹理） |
| 标题字体 | **衬线体**（宋/楷方向）——历史厚重感 |
| 正文字体 | 黑体，但字重偏中等，**不用细体**（细体在沙色底上会发虚） |
| 数字 | **不用等宽**——等宽数字太"工程"，与敦煌气质冲突 |

**动效**：慢（基准时长 ×1.3）、有尘土感、无高光扫过

**禁用**：金属高光、渐变彩虹、任何"闪耀"效果

### 9.2.3 赛博蓝 `cyber-blue`

| 项 | 内容 |
| :--- | :--- |
| **触发** | 一线城市 · 夜景为主的城市行 · 港澳 |
| **意象** | 深夜高架、玻璃幕墙反射、便利店灯箱、雨夜车灯 |
| **光的性格** | **冷、锐、人造**。有明确的发光点，也有明确的暗部 |
| **气质词** | 速度 · 精密 · 不眠 |

**配色**

| 角色 | 色值 | 来历 |
| :--- | :--- | :--- |
| 主色 | `#00A3FF` | 电光蓝——**高饱和，允许发光** |
| 辅色 | `#FF2D78` | 品红——霓虹招牌的第二色 |
| 底色 | `#0A1628` | 夜——**深蓝黑，不是纯黑**（纯黑上发光会"脏"） |
| 强调 | `#00E5C0` | 电子青——用于数据/状态 |
| 文字 | `#E8F1FF` | 冷白 |

**材质与字体**

| 项 | 设计 |
| :--- | :--- |
| 材质 | 玻璃（**有高光反射**，与敦煌金相反）、霓虹辉光 |
| 字体 | 无衬线几何体，**数字用等宽**——这里等宽是对的，有仪表感 |
| 字重 | 可以细——深底上细字反而清晰 |
| 动效 | 快（基准时长 ×0.8）、有电子扫描感、允许辉光呼吸 |

> 📌 **注意「底色用深蓝黑 `#0A1628` 而不是纯黑」这条。**
>
> 纯黑底上做发光，光晕的边缘会**发灰发脏**——因为纯黑和发光色之间的过渡缺少中间调。
> 深蓝黑提供了一点底色，光晕过渡就干净了。
>
> **这是夜店灯光和舞台灯光的区别：好的舞台从不全黑。**

**禁用**：暖色大面积铺陈、纸质纹理

### 9.2.4 高原青 `plateau-cyan`

| 项 | 内容 |
| :--- | :--- |
| **触发** | 西藏 · 川西 · 甘南 · 青海高原段 · 海拔 3000m+ |
| **意象** | 高原的天、冰川融水、经幡的蓝、牦牛毛帐篷 |
| **光的性格** | **通透、稀薄、冷得干净**。紫外线强，对比度高，阴影发蓝 |
| **气质词** | 辽阔 · 澄澈 · 缺氧的安静 |

**配色**

| 角色 | 色值 | 来历 |
| :--- | :--- | :--- |
| 主色 | `#1E6F8C` | 高海拔靛青——**比平原的天空更深更纯** |
| 辅色 | `#C9A227` | 藏黄——经幡/袈裟上的黄，用量**极少** |
| 底色 | `#EFF6F8` | 稀薄空气的白——**带极淡的青**，不是暖白 |
| 强调 | `#D94F3D` | 僧袍红——**只用于警告与关键标记** |
| 文字 | `#1A2E38` | 深青黑 |

> 📌 **「高海拔的天更蓝更深」不是文学修辞，是事实。** 海拔越高，大气散射越少，天空的蓝越接近靛色。**从真实物理出发取色，得到的颜色自己就会"对"。**

**材质与字体**

| 项 | 设计 |
| :--- | :--- |
| 材质 | 稀薄通透的玻璃（低模糊、高通透）、冰面 |
| 字体 | 无衬线，字距**略宽**——旷野感 |
| 留白 | **五个主题里最多的一个**（高原的空旷要留在版面上） |
| 动效 | 极慢（基准时长 ×1.5）、无弹跳、几乎只有淡入淡出 |

**禁用**：高饱和暖色铺陈、密集装饰

### 9.2.5 江南翠 `jiangnan-emerald`

| 项 | 内容 |
| :--- | :--- |
| **触发** | 江浙沪 · 皖南 · 水乡 · 园林 |
| **意象** | 雨后青苔、龙井茶园、乌篷船、宣纸、青瓷 |
| **光的性格** | **湿的、漫射的、柔和的**。没有直射光，一切都有柔边 |
| **气质词** | 温润 · 内敛 · 潮气 |

**配色**

| 角色 | 色值 | 来历 |
| :--- | :--- | :--- |
| 主色 | `#3E6B5A` | 青苔绿——★ **偏灰的青绿，不是翠绿** |
| 辅色 | `#7A8B7F` | 烟灰绿 |
| 底色 | `#F5F2EA` | 宣纸——**偏暖，不是冷白** |
| 强调 | `#9C4A3C` | 朱砂——印章红，**用于落款式标记** |
| 文字 | `#2B3330` | 墨黑（带绿的墨） |

> 🔴 **「偏灰的青绿，不是翠绿」是本主题最关键的决策。**
>
> 江南的绿**从来不是鲜艳的**——它是雨天的、有雾的、被水汽过滤过的。做成 `#00C853` 那种翠绿，出来是**塑料感**，像仿古街的新漆。
>
> **江南的美在"旧"和"润"，不在"艳"。** 把饱和度降下来、把灰度加上去，出来的才对。

**材质与字体**

| 项 | 设计 |
| :--- | :--- |
| 材质 | 宣纸（**可见的纤维纹理**）、瓷器釉面（柔和高光） |
| 字体 | 标题可用**楷**（文人气）——但不能用行草，辨认成本太高 |
| 字号 | 略小、行距略大——**疏朗**，不是紧凑 |
| 动效 | 柔和、**水墨扩散式**（不是位移式）、无弹跳 |

**禁用**：高饱和色、硬边阴影、金属质感

### 9.2.6 冰川银 `glacier-silver`

| 项 | 内容 |
| :--- | :--- |
| **触发** | **默认兜底** · 极地 · 雪山 · 无法归类时 |
| **意象** | 冰川、雪原、磨砂金属、阴天的海 |
| **光的性格** | **中性、无性格**——这正是它作为兜底的原因 |
| **气质词** | 干净 · 克制 · 不打扰 |

**配色**

| 角色 | 色值 | 来历 |
| :--- | :--- | :--- |
| 主色 | `#5A6B78` | 岩灰蓝 |
| 辅色 | `#8FA3B0` | 冰蓝灰 |
| 底色 | `#F7F9FA` | 雪白（**带极淡的蓝**，不是米白） |
| 强调 | `#2E7DA8` | 冰裂蓝——**唯一的彩色**，用于交互 |
| 文字 | `#1C2529` | 石墨黑 |

> 📌 **兜底主题的设计原则是「不表达立场」。**
>
> 用户去了一个 TripCraft 不认识的地方——**这时产品不该瞎猜一个意象**（猜错了比不猜更尴尬），而应该给一套**中立、干净、不抢戏**的视觉，让**内容和照片成为主角**。
>
> **冰川银的"没有性格"，就是它的性格。**

**通用性**：唯一一套**不需要任何调整就能与全部五种流派搭配**的主题。

## 9.3 五大设计流派的完整设计

### 9.3.1 流派是什么，不是什么

> ⚠️ **流派不是「换一套颜色」。** 那是主题干的事。
>
> **流派换的是：材质语言、排版逻辑、信息密度、动效性格。** 换完之后，**即使颜色完全一样，看起来也是两个不同的产品。**

**自检方法**：如果两个流派去掉颜色后看起来一样，那它们不是两个流派。

### 9.3.2 五大流派对照

| | 🍏 Apple 液态玻璃 | 🤖 Material You | 🪵 复古拟物 | 📐 瑞士极简 | 🌌 赛博 HUD |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **一句话** | 光穿透玻璃 | 颜色从目的地长出来 | 一本探险家的手账 | 信息本身就是美 | 夜巡仪表盘 |
| **材质** | 高透磨砂、多层悬浮 | 柔和高对比卡片 | 牛皮纸、黄铜、火漆 | 无材质（纯平面） | 暗底发光 |
| **圆角** | 大（连续曲率） | **极大**（接近胶囊） | 小（纸张是方的） | **零** | 中（切角） |
| **信息密度** | 中 | **低**（大留白） | 中高（手账本来就密） | **极高** | 高 |
| **主色来源** | 主题决定 | ★ **从目的地照片提取** | 主题决定 | **固定黑白灰 + 单一亮色** | 主题决定 |
| **动效性格** | 弹性、有重量 | 流动、缓慢展开 | 机械、翻页感 | **几乎没有** | 扫描、刷新 |
| **字体** | 系统无衬线 | 温润无衬线 | **衬线 + 手写标注** | 无衬线几何体 | 等宽 + 无衬线 |
| **最佳搭配** | 任意 | 任意 | 敦煌金 / 江南翠 | 任意 | 赛博蓝 / 冰川银 |

### 9.3.3 三个流派的详细设计

#### 🪵 Vintage Skeuomorphism · 复古探索家手账

**核心主张**：**这是一本被翻旧的纸质手账，不是一块屏幕。**

| 元素 | 设计 | 为什么 |
| :--- | :--- | :--- |
| 底色 | 牛皮纸暗纹，**四角有做旧的暗角** | 纸是被翻过的 |
| 打卡标记 | **火漆印章**——按下时有压印动效 | 印章是"确认"的古老隐喻 |
| 地点标记 | **黄铜图钉**，有真实投影 | 图钉把纸钉在板上 |
| 分页 | 页边有**便签条凸出**，可点 | 纸质手账的真实用法 |
| 路线 | **红色棉线**（不是发光线条） | 手工标注 |
| 手写体 | 用于**批注**，不用于正文 | 辨认成本 |

> ⚠️ **拟物化的最大风险是「假」。** 做得不到位的拟物，比扁平化更廉价。
>
> **判断标准：这个材质如果真实存在，它会这样反光吗？**
> 牛皮纸**不会**有镜面高光；黄铜**会**有。火漆印**不会**投出硬阴影。**违反物理直觉的拟物，一眼就假。**

#### 📐 Swiss International Minimalist · 瑞士国际主义

**核心主张**：**去掉一切装饰，让信息自己说话。**

| 元素 | 设计 | 为什么 |
| :--- | :--- | :--- |
| 网格 | **严格的 12 列网格**，所有元素对齐到网格 | 秩序感来自对齐，不是来自装饰 |
| 圆角 | **零**——全直角 | 圆角是装饰 |
| 色彩 | 黑白灰 + **一个亮橙**（`#FF5A00`） | 唯一的颜色用来指路 |
| 字重 | 极端的粗细对比（标题超粗，正文超细） | 层级靠字重，不靠颜色 |
| 留白 | 有节奏，**但不是 Material 那种"大"** | 瑞士的留白是**精确**，不是**宽松** |
| 动效 | **几乎没有**。只有必要的状态切换 | 动效是装饰 |
| 数字 | 等宽，**且大量使用**（里程/时长/海拔） | 数据是行程的骨架 |

> 📌 **瑞士极简与 Material You 都"留白"，但完全不同。**
>
> **Material 的留白是「呼吸」**（大而软，配大圆角）；**瑞士的留白是「切割」**（锐利、精确、配直角）。
>
> **外行会觉得它们像，因为都"干净"。** 但把它们并排放在一起，气质完全相反——**一个是舒服，一个是清醒。**

#### 🌌 Cyberpunk Dark HUD · 赛博夜巡仪表盘

**核心主张**：**这是一个正在运行的仪表盘，不是一篇文章。**

| 元素 | 设计 | 为什么 |
| :--- | :--- | :--- |
| 边界 | **切角**（不是圆角，是 45° 切角） | 切角是军工/仪表的语言 |
| 数据 | 大量实时数值（速度/海拔/剩余油量/气温） | HUD 的本分 |
| 路线 | **荧光绿主路 + 电光青备选**双色 | README §5.2 已定义 |
| 网格 | 背景有**极淡的扫描网格线** | 雷达屏 |
| 动效 | **扫描线扫过**、数值跳动、状态切换有"刷新"感 | 仪表在工作 |
| 字号 | **小**，但**全部大写/等宽** | 航空航天仪表传统 |

> ⚠️ **赛博 HUD 有一个必须防的坑：可读性。**
>
> 发光文字 + 暗底 + 小字号 = **晚上开车看不清楚**。
>
> **约束**：正文**不允许用发光效果**，只有标题与数据允许；发光文字的对比度**仍须达到 7:1**（见 [§9.7](#97-可访问性底线)）。
>
> **风格不能凌驾于"开车时要能看清"之上。**

## 9.4 ★ 液态玻璃的设计语言：五层景深

README §4.2 写了「五层景深」，**但没有定义是哪五层**。本节补上。

### 9.4.1 五层的定义

| 层 | 名称 | 内容 | 模糊 | 阴影 | 透明度 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **L0** | 意境层 | AI 文生图背景 / 渐层 | 0（本身清晰） | 无 | — |
| **L1** | 容器层 | 卡片底板、面板 | **最厚** | 小 | 中 |
| **L2** | 内容层 | 卡片内的文字与图形 | 无 | 无 | 不透明 |
| **L3** | 浮动层 | 吸底工具条、悬浮药丸 | 中 | **中** | 中高 |
| **L4** | 模态层 | 全屏展开、抽屉 | 薄 | **最大** | 高 |

### 9.4.2 两条贯穿的规则

> **规则一：越靠近眼睛，越清晰。**
> 模糊半径从 L1 → L4 **递减**。
>
> **规则二：越靠近眼睛，投影越大。**
> 阴影从 L1 → L4 **递增**。

📌 **这两条规则合起来，就是「景深」的全部。** 它们之所以成立，是因为**它们符合物理直觉**——现实里离眼睛近的东西就是更清晰、投影更大。

> 🔴 **反过来说：如果一个界面的模糊和阴影是随机分配的，用户看不懂层级，就会觉得"乱"——即使他说不出哪里乱。**
>
> **景深是让用户"不用思考就知道什么在上面"的机制。** 它不是装饰。

### 9.4.3 玻璃的参数不是固定的

| 场景 | 调整 | 原因 |
| :--- | :--- | :--- |
| **长辈模式** | 模糊**降低**，底色**更实** | 玻璃透出的背景会干扰阅读 |
| **强光户外** | 模糊**降低**，对比度**提高** | 阳光下玻璃效果几乎看不见，反而降低对比 |
| **赛博流派** | 允许**辉光** | 流派的材质语言 |
| **高原青主题** | 模糊**降低**、通透度**提高** | 主题的"稀薄"意象 |

> 📌 **「强光户外降低模糊」是一条来自母本《西行计划 · 丝路自驾路书》（`JohnMaxwell0123/Trip`）的真实教训。**
>
> **液态玻璃在户外阳光下会失效**——屏幕反光加上低对比，玻璃卡片看起来就是一块糊掉的白斑。
>
> **所以玻璃效果必须是「渐进增强」的**：能显示时显示，不能显示时退化为实色卡片，**而不是硬撑着显示**。这与[铁律 3 降级不可耻，白屏才是罪](00-overview-and-glossary.md#铁律-3--降级不可耻白屏才是罪-degrade-never-blank)同源。

## 9.5 排版系统

### 9.5.1 字号阶梯

| 层级 | 标准模式 | 长辈模式 | 用途 |
| :--- | :--- | :--- | :--- |
| 特大标题 | 32px | **44px** | 开屏、章节名 |
| 大标题 | 24px | **34px** | 当天标题 |
| 小标题 | 19px | **26px** | 景点名、时间点 |
| 正文 | 16px | **22px** | 说明文字 |
| 辅助 | 14px | **19px** | 备注、次要信息 |
| 最小 | **12px（下限）** | **17px** | ⚠️ 绝对不低于此 |

> ⚠️ **12px 是下限，不是常态。** 中文在 12px 以下笔画会粘连（尤其"鑫""藏""麟"这类字），**辨认成本陡增**。
>
> **多数产品的最小字号是 10px 或 11px——那是照抄英文排版规范的结果。中文字形更复杂，照搬会出事。**

### 9.5.2 行高与字距

| 项 | 标准 | 长辈 | 原因 |
| :--- | :--- | :--- | :--- |
| 正文行高 | 1.6 | **1.8** | 长辈需要更宽的行走通道 |
| 标题行高 | 1.3 | 1.4 | — |
| 中文字距 | 0 | **+0.02em** | 中文字形方正，密排会粘 |
| 数字字距 | 略收紧 | 0 | 数字有天然的字间距 |

### 9.5.3 字体选择的硬约束

| 约束 | 说明 |
| :--- | :--- |
| **不加载网络字体** | [铁律 1 零构建](00-overview-and-glossary.md#铁律-1--零构建交付-zero-build-delivery) + 离线可用 |
| **只用系统字体** | 各平台自带的黑体/宋体 |
| **必须声明完整字体栈** | 否则跨平台会退化到衬线，气质全毁 |
| **数字用 `font-variant-numeric`** | 需要对齐的场合（账本、时刻表）启用等宽数字 |

> 📌 **"不加载网络字体"是一条会带来设计妥协的约束**，但它换来的是：**在任何网络条件下都能秒开、且离线也能正确显示**。
>
> **这个交换是划算的**——因为旅行场景恰恰是网络最不稳定的场景。**一个字体加载失败导致排版崩坏的路书，比一个用系统字体的好路书糟糕得多。**

## 9.6 动效语言

### 9.6.1 什么该动，什么不该动

| 该动 | 说明 |
| :--- | :--- |
| ✅ **状态转换** | 展开/折叠、层级变化、页面切换 |
| ✅ **操作反馈** | 点击、下拉、加载 |
| ✅ **注意力引导** | 新内容出现、警告升起 |
| ✅ **进度表达** | 生成中、上传中 |

| 不该动 | 说明 |
| :--- | :--- |
| ❌ **阅读中的正文** | 文字位移会打断阅读 |
| ❌ **地图** | 地图自带惯性与手势，叠加动画会冲突 |
| ❌ **纯装饰** | 无信息量的动效就是消耗 |
| ❌ **背景视差（长辈模式）** | 会加重眩晕 |

> 🔴 **「阅读中的正文不动」是一条容易被违反的规则。**
>
> 很多产品喜欢让文字"淡入"——看起来优雅。但**当用户已经在读的时候，任何位移都等于把阅读位置清零**。
>
> **规则：进入视口时淡入可以，但已经进入视口的内容不允许再动。**

### 9.6.2 时长基准

| 类型 | 标准 | 长辈模式 | 说明 |
| :--- | :--- | :--- | :--- |
| 微反馈（点击） | 100ms | **150ms** | 超过 150ms 会觉得迟钝 |
| 状态切换 | 250ms | **380ms** | — |
| 面板展开 | 350ms | **520ms** | — |
| 载体切换 | 500ms | **750ms** | — |

**长辈模式统一 ×1.5**，且**必须同时遵守系统的「减少动态效果」设置**，二者叠加时以系统设置为准。

### 9.6.3 缓动

| 场景 | 缓动性格 |
| :--- | :--- |
| 元素进入 | 减速（快起慢停） |
| 元素离开 | 加速（慢起快走） |
| 位置移动 | 先加速后减速 |
| **长辈模式** | 全部改为**线性**——缓动会让长辈觉得"卡" |

> 📌 **最后一条反直觉但重要：** 缓动（easing）是给"有期待感的用户"设计的，它让动效显得"有重量"。但**对不熟悉动画的长辈，缓动会被读成"设备卡了"**。
>
> **同一段动画，年轻人看到"优雅"，长辈看到"卡顿"。** 所以长辈模式用线性。

## 9.7 可访问性底线

**这不是"加分项"，是底线。达不到就不允许发布。**

| 项 | 标准 | 依据 |
| :--- | :--- | :--- |
| **正文对比度** | ≥ 4.5:1 | WCAG AA |
| **长辈模式对比度** | ≥ 7:1 | WCAG AAA |
| **触控靶尺寸** | ≥ 44×44px | WCAG / Apple HIG |
| **长辈模式触控靶** | ≥ **48×48px** | README §4.2 已定义 |
| **颜色不是唯一信息通道** | 必须同时有图标或文字 | WCAG 1.4.1 |
| **支持系统字号放大** | 放大到 200% 不破版 | WCAG 1.4.4 |
| **禁止纯装饰性闪烁** | 无 3Hz 以上闪烁 | WCAG 2.3.1 |

### 9.7.1 ★ 颜色三重编码

**「红 = 危险」对色盲用户无效。** 所有状态信息必须**同时**用三个通道表达：

| 状态 | 颜色 | 图标 | 文字 |
| :--- | :--- | :--- | :--- |
| 安全 | 绿 | ✓ | 「正常」 |
| 注意 | 黄 | ⚠ | 「注意」 |
| 危险 | 红 | ✕ | 「危险」 |

> ⚠️ **红绿色盲占男性人口约 8%。** 一个五人车队里，平均有 0.4 个红绿色盲。
>
> **如果"路况危险"只用红色表达，那这个提醒对一部分人是完全不存在的**——而这恰恰是最不能漏掉的提醒。
>
> 这也直接呼应[铁律 8 拒绝静默失败](00-overview-and-glossary.md#铁律-8--拒绝静默失败-never-fail-silently)：**只靠颜色传达的信息，对色盲用户就是静默失败。**

### 9.7.2 长辈模式的真实设计目标

> 🔴 **长辈的困难不是「看不清」，是「找不到」。**
>
> 只把字放大，解决不了问题——**因为信息总量没变，字大了反而一屏装不下，更难找。**

**长辈模式的四个动作**：

| # | 动作 | 说明 |
| :--- | :--- | :--- |
| 1 | **字更大** | 见 §9.5.1 |
| 2 | **★ 信息更少** | 隐藏次要信息，**不是把同样的内容放大** |
| 3 | **★ 层级更浅** | 主路径**不超过 2 层**。"点进去再点进去"对长辈是灾难 |
| 4 | **操作更明确** | 每个按钮说清楚点了会发生什么，**不用图标代替文字** |

> 📌 **第 2 条和第 3 条是真正起作用的部分，也是最常被忽略的。**
>
> **"把字放大"是名义上的无障碍，"把东西变少"才是实际的关怀。**

## 9.8 本章设计清单

| # | 设计决策 | 一句话 |
| :--- | :--- | :--- |
| V-01 | **流派定形，主题定色** | 两者正交组合，解决 README 结构性矛盾 |
| V-02 | **提供兼容性矩阵并提前拦截** | 不让用户生成四不像再后悔 |
| V-03 | **免费版不阉割色彩，只区分形体** | 与 §5.1 承诺一致 |
| V-04 | **每套主题从真实意象提取，不发明颜色** | 敦煌金是"氧化的金"不是"闪耀的金" |
| V-05 | **暖底不用纯黑，暗底不用纯黑** | 两个原因不同，结论相同 |
| V-06 | **底色带色相**（暖白/冷白/青白） | 纯白是设计上的偷懒 |
| V-07 | **江南的绿必须降饱和** | 艳丽 = 塑料感，江南美在"旧"和"润" |
| V-08 | **冰川银是"无性格的兜底"** | 猜错意象比不猜更尴尬 |
| V-09 | **五层景深：越近越清晰，越近影越大** | 符合物理直觉才成立 |
| V-10 | **玻璃效果是渐进增强，不是硬撑** | 阳光下玻璃会失效 |
| V-11 | **中文字号下限 12px** | 照抄英文规范会出事 |
| V-12 | **不加载网络字体** | 用可加载性换离线可用 |
| V-13 | **已进入视口的内容不再动** | 位移 = 阅读位置清零 |
| V-14 | **长辈模式动效改线性** | 缓动被读成"卡了" |
| V-15 | **状态三重编码（色+形+字）** | 8% 男性红绿色盲 |
| V-16 | **长辈模式的目标是"信息更少"** | 不是"字更大" |
