# ADR-009 模型接入抽象与用户自带 API（BYOK）

- **status**: Proposed
- **date**: 2026-10-17
- **背景与约束**：
  产品基线 v3 要求 AI 对话窗口"类似 GPT 和 Claude 的输入框，也可换用客户自己喜欢的 API"（[PRD-01 §1](../../product/PRD-01-vision-positioning.md#1-产品定位)）。因此系统需要同时支持：① 平台提供的默认模型；② 用户自带 Key 的第三方模型。约束有三条：
  1. 用户的 Key 是高价值凭证，泄露后果由用户承担，平台不应成为它的保管方（[docs/00 铁律 4](../../00-overview-and-glossary.md#铁律-4--数据主权本地化-local-data-sovereignty)）；
  2. 无论模型来源，产出必须经过同一条防幻觉与合规管线（[ADR-008](ADR-008-ai-generation-guardrails.md)）；
  3. 图商 Key、匹配数据等平台资产不能下发到客户端（[ARC-07 §2](../ARC-07-security-privacy-compliance.md#2-威胁建模与滥用防护清单-threat--abuse-matrix)）。

- **选项对比**：
  - **选项 A：用户 Key 上传平台加密保存，由服务端统一调用**
    - *优点*：编排逻辑只有一份，全部在服务端。
    - *代价*：平台成为所有用户 Key 的集中存放点；一次泄露波及全部用户。
    - *风险*：用户难以信任；任何服务端日志误打印都可能泄露 Key。
  - **选项 B：用户 Key 只存设备；自带模型由客户端直连调用；工具（图商检索、匹配、校验）以平台 API 形式提供给客户端编排器**
    - *优点*：平台从不接触用户 Key；平台资产仍留在服务端；平台模型与自带模型共用同一套工具 API 和校验管线。
    - *代价*：需要一个可在客户端运行的编排器（与服务端编排器共用代码包）；Web 端直连部分服务商需要处理跨域。
    - *风险*：客户端编排器可被篡改——但篡改者只能影响自己的会话，且最终写入行程空间的 DSL 仍由服务端校验。
  - **选项 C：只支持平台模型**
    - *优点*：最简单。
    - *代价*：不满足业主要求。

- **评估标准**：用户凭证安全（一票否决）、产出质量底线是否随模型变化、平台资产是否外泄、实现复杂度。

- **建议决策 (Proposed)**：
  **采纳选项 B。**
  1. **模型抽象层 `ModelProvider`**：统一 `chat`、`structuredOutput(schema)`、`toolCall(tools)` 三个能力；首批适配 OpenAI 兼容接口与 Anthropic 接口；平台默认模型（D5）也通过同一抽象接入。
  2. **Key 存储**：仅存于设备的加密存储（App 使用系统钥匙串；Web 使用加密的 IndexedDB），不随行程空间同步，不进入任何服务端日志。换设备需重新添加。
  3. **编排位置**：平台模型 → 服务端编排；自带模型 → 客户端编排。两者调用同一组平台工具 API：`S-GEO.SearchPOI` / `SearchAlongRoute` / `EstimateDriveTime`、`S-MATCH.MatchRoutes`、`S-GENERATE.ValidateProfile` / `ValidateDraft`。
  4. **校验在服务端**：需求画像与行程草案写入行程空间前，必须通过服务端校验（契约、图商核验、BR-015 词表、BR-025）。客户端编排器的输出不被信任。
  5. **能力检测**：添加 Key 时用一个最小结构化输出请求探测能力；不支持结构化输出的模型只能用于自由聊天，规划步骤回落到平台模型并标注。
  6. **发送前脱敏**：任何模型请求发出前，客户端把姓名、证件号、手机号替换为占位符。

- **影响**：
  - 新增后端逻辑模块 `S-AI`（平台模型网关、额度计量）与 `S-MATCH`（[ADR-010](ADR-010-route-matching-scoring.md)），见 [ARC-05](../ARC-05-backend-integrations.md)。
  - 新增共享代码包 `packages/agent-core`（编排器，客户端与服务端共用）。
  - 平台模型的推理成本按额度计量（PRD-05）；自带 Key 的调用不产生平台推理成本。
  - 合规：平台默认模型须为可合规对公众提供服务的模型；自带模型的服务商在境外时涉及数据出境告知。适用性待律师核验（OI-022）。

- **重新评估的触发条件**：
  主流模型服务商普遍提供"委托授权"（OAuth 式的受限令牌）时，重新评估是否由服务端代为调用；或客户端编排器的维护成本显著高于预期时。
