# ADR-005 地图与路线服务抽象及供应商选择

- **status**: Proposed
- **date**: 2026-10-08
- **背景与约束**：
  地图服务直接影响 POI 准确度、算路耗时预估及座舱深链投递（关联 [PRD-01 §5](../../product/PRD-01-vision-positioning.md#5-能力边界规范-scope--boundaries)、[A-09](../../ASSUMPTIONS.md)）。中国大陆地区对测绘资质与地图服务有严苛法律要求，且商业图商商用条款明确禁止持久化存储算路路线几何（polyline，详见 BR-025 规则）。

- **选项对比**：
  - **选项 A：合规商用图商抽象层 (高德地图优先 + 百度地图冗余备选)**
    - *优点*：高德/百度具备中国境内法定审图号与全量合规测绘资质；全国路网时效性强；支持主流座舱系统 URI Scheme 深链唤起；通过封装 `S-GEO` 适配层屏蔽图商私有 API 差异。
    - *代价*：商业 API 调用存在阶梯计费成本；受制于图商商用条款约束（禁止离线存储算路几何）。
    - *风险*：图商接口限流或商用授权价格上涨。
  - **选项 B：开源自建地图服务 (OpenStreetMap / OSRM)**
    - *优点*：无外部 API 调用成本，数据完全自主可控。
    - *代价*：中国大陆地区境内审图号合规风险极高（属于违法测绘与非法发布地图红线）；自驾 POI 详情、餐饮营业时间与限行路况严重滞后缺失。
    - *风险*：触犯《测绘法》行政处罚高压线，导致产品被依法关停封禁。

- **评估标准**：测绘合规性（零容忍红线）、自驾 POI 覆盖全面性、车载地图兼容度、API 成本可控性。

- **建议决策 (Proposed)**：
  **采纳选项 A**。采用 **高德地图作为主服务商 + 百度地图作为备选冗余，前端统一封装在 `S-GEO` 适配器中**。
  严格执行 BR-025 门禁：仅落库 POI 离散经纬度点，绝不落库算路 API 返回的密集 polyline；在客户端一律通过系统级深链（Scheme）直接唤起车载/手机原生地图计算实时导航。

- **影响**：
  保障严格满足测绘与法律合规；通过服务商抽象层降低厂商锁定风险。

- **重新评估的触发条件**：
  若未来拓展至境外自驾业务（如中亚丝路或欧洲自驾），境外部分引入 Google Maps / Mapbox 适配器。
