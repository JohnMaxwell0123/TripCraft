# ADR-008 AI 生成管线与幻觉防护机制

- **status**: Proposed
- **date**: 2026-10-08
- **背景与约束**：
  大模型生成旅行行程时普遍存在“编造虚构景点、胡排反常作息时间、推荐未经开发的危险无人区野景点”等高风险幻觉（关联 [PRD-01 §5](../../product/PRD-01-vision-positioning.md#5-能力边界规范-scope--boundaries)、[ARC-05 §4](../ARC-05-backend-integrations.md#4-ai-生成管线与防幻觉护栏-ai-pipeline--guardrails)、[A-11](../../ASSUMPTIONS.md)）。系统不能直接采纳大模型的无约束文本输出。

- **选项对比**：
  - **选项 A：分阶段提示工程 + 外部图商硬校验 + 待定项 (Tentative) 弹性回显**
    - *优点*：大模型仅负责“意图提取与初步序列求解”，所有地点与营业时间必须经由合规图商官方 API 强校验；未核验项严格标为 `tentative: true`；结合 BR-015 违规词与涉密坐标黑名单扫描；层层设防，可控性极高。
    - *代价*：生成流水线相对单次 Prompt 复杂，需要集成结构化输出解析器。
    - *风险*：若图商接口偶然宕机，需有合理的降级回显策略。
  - **选项 B：端到端单次大模型自由生成（Direct End-to-End LLM Prompting）**
    - *优点*：实现极其简单，单次 API 调用直接返回 Markdown 或 JSON。
    - *代价*：完全无法杜绝幻觉；极易推荐已被封禁的危险野路线，平台承担连带行政法律责任；生成的坐标经纬度严重飘移导致车机导航错误。
    - *风险*：严重破坏用户对自驾路书专业性与安全性的信任基础。

- **评估标准**：自驾安全与法律合规（一票否决项）、生成结构合规率（严格符合 JSON Schema 契约）、用户参与确认感。

- **建议决策 (Proposed)**：
  **采纳选项 A**。采用 **苏格拉底结构化澄清 ➔ 草案提取 ➔ 图商二次硬核验 ➔ 待定项显式回显的确定性防护管线**。
  绝不在没有图商 POI 核验的情况下将大模型生成的地点作为“确信景点”落库；不符合闭馆规则的排程在编译期由规则引擎予以自动纠偏或标出冲突。

- **影响**：
  从工程机制上守住产品专业与安全红线；确保输出完全契合 `spec/trip.schema.json` 契约规范。

- **重新评估的触发条件**：
  当底层基础大模型自身原生具备通过多模态地理空间验证达到 99.9% 真实精度的能力时重新评估。
