# Unify GTM 页面美学 · 演示站视觉规范（2026-10-20 实测复核）

> **适用范围**：只约束 `apps/showcase` 演示站。产品 UI 的视觉体系 D10 已于 2026-10-22 定下（[PRD-01 §9](../../docs/product/PRD-01-vision-positioning.md#9-待业主确认的决策)）：App 外观按 [SHOWCASE §4.1「视窗界面规范」](../../docs/SHOWCASE-web-design.md#41-共用外壳与应用视窗)，会员行程皮肤按 [`docs/09` §9.0](../../docs/09-visual-design-system.md#90-两层app-外观与行程皮肤)；本规范不约束二者。
>
> **来源**：2026-10-20 用无头 Chrome 打开 unifygtm.com 首页、`/product/agents`、`/customers`、`/pricing`，在 1440 × 900 与 375 × 812 两种宽度下逐屏截图，并读取计算样式（字号、行高、字距、颜色、圆角、边框、阴影、间距）。本文的数值都来自这次实测；上一版规则是早先凭印象总结的，与实测不符的地方见附录 B。
>
> **只学原则，不搬素材**：不使用 Unify 的文案、Logo、插画、照片与截图；它的字体 Feature Text、Saans 是商用字体，这里用 Noto Serif SC 与系统中文无衬线替代。品牌始终是 TripCraft · 旅艺。

---

## 1. 基调

- **编辑出版物的排版 + 克制的产品界面**：大号衬线标题、充足留白、几乎没有装饰；产品界面以真实窗口的样子出现。
- **画布**：暖纸白 `#FFFFF9`（实测 `rgb(255,255,249)`）。不用冷白 `#FFFFFF` 或 `#F8FAFC` 铺满页面。
- **深色区**：全出血的「氛围带」——Unify 用动态模糊的实景照片；我们用渐变 + 高斯模糊画出同样的质感（`.atmo-*`，见 §9），不引入外部图片。
- **主色只有两种**：炭黑 `#241E20` 与烈焰橙 `#FE3C01`；橙色只用来指出重点（§4）。

## 2. 版心、栅格与留白

| 项 | Unify 实测 | 演示站规范 |
| :--- | :--- | :--- |
| 内容宽度 | `min(100% - 40px, 1240px)`；1440 宽时左右各 100px | 外框 `max-w-[1320px]` + `px-5 sm:px-8 lg:px-10` → 桌面内容宽 1240px，手机两侧 20px。所有分区共用这一条网格 |
| 分区间距 | 分区之间 120–170px；不画分隔线 | 分区上下 `py-24 md:py-32`（96 / 128px）；同底色的相邻分区只靠留白分开，不加 `border-t` |
| 首屏 | H1 距导航约 74px | 首屏标题距导航 56–96px |
| 演示舞台 | 左侧选项卡约占 45%，右侧窗口 | 左栏 300–340px（标题、章节导航、播放控制），右侧窗口占满剩余宽度（桌面约 840px，保证窗口内的 `cq-lg` 版式） |

## 3. 字体与字号阶梯

| 角色 | Unify 实测 | 演示站规范（中文） |
| :--- | :--- | :--- |
| 展示衬线 | Feature Text | `font-serif`：Noto Serif SC（非阻塞加载，见 §12）→ 思源宋体 → 系统宋体 → Georgia |
| 界面无衬线 | Saans 400–500，正文常用 450 | `font-sans`：Plus Jakarta Sans（拉丁）+ PingFang SC / 鸿蒙黑体 / 微软雅黑 |
| H1 | 90–100px / 700 / 行高 1.0 / 字距 −0.04em；手机 48px | 72px（桌面）· 56px（平板）· 40px（手机）/ 700 / 行高 1.04–1.08 / 字距 −0.03em；左对齐 |
| 分区 H2 | 56px / 700 或 400 / 行高 1.05 / −0.04em | 44px（桌面）· 40px · 32px（手机）/ 600 / 行高 1.15 / −0.02em |
| 陈述式 H2（带关键词强调） | 40–44px / 400 / 行高 1.1–1.2 / −0.03em | 舞台标题 38px / 600，关键词纯橙色（§4） |
| 卡片 / 特性标题 | 24px / 450 衬线；选项卡标题 28px 无衬线 400 | 卡片标题衬线 22px / 600；选项卡（章节）标题无衬线 20px / 400 |
| 大数字 | 72–80px / **400**（常规字重）/ −0.03em；方块里 32px | 数字卡 44–56px / 400；场景方块 28–30px / 500 |
| 导语 | 20px / 450 / 行高 1.3 | 18–20px，行高 1.6（中文需要更松） |
| 正文 | 16px / 400–450 / 行高 1.4 | 15–16px，行高 1.6–1.7 |
| 导航、按钮 | 16px / 500 | 15px / 500（中文 15px ≈ 拉丁 16px 的视觉大小） |

| 辅助字、脚注 | 12px 左右，只用于脚注 | 13–14px；视窗内的界面辅助字不小于 12px；**不再出现 10–11px** |

- 中文标题的换行：短语不能被拆开时加 `whitespace-nowrap` 或 `break-keep`（例如首屏的「定下来」）；`break-keep` 只用在每段都短于一行的标题上。

## 4. 颜色与烈焰橙的用法

| 令牌 | 值 | 用途 |
| :--- | :--- | :--- |
| 画布 | `#FFFFF9` | 页面、卡片、窗口底色 |
| 平铺块 | `#F8F7F3` | 数字 / 场景方块、卡片里的演示区（`.u-tile`） |
| 炭黑 | `#241E20` | 文字、主按钮、公告条 |
| 次级文字 | 炭黑 75% / 70% | 导语与正文（对比度 ≥ 6:1） |
| 弱文字 | 炭黑 60–65% · `#6F6A64` | 脚注、页脚分组名（Unify 用 `#A3A3A3`，对比度只有 2.5:1，这里加深到 ≥ 4.5:1） |
| 未选中的选项卡 | 炭黑 62% | 仍满足 4.5:1 |
| 烈焰橙 | `#FE3C01`（深色底上用 `#FF6A3D`） | 见下 |
| 小号橙字 | `#C43200` | 12–13px 的橙色文字（对比度 ≥ 4.5:1） |
| 发丝线 | 卡片 `rgba(163,163,163,.2)`；胶囊 `rgba(139,139,139,.24)`；窗口 `#D7D7CF` | — |

**烈焰橙只出现在四类地方**（与 Unify 实测一致）：

1. 标题里的关键词——纯色，不加光晕（例：「说清需求，**自驾**或**旅行社线路**任你选」）；
2. 1px 竖线（数字 / 时间轴的左边线）与选项卡、章节的进度条；
3. 需要注意的信号：推断项、低置信度字段、路线描绘、星级、表格分组标题、「最受欢迎」这类小标签；
4. 首屏关键词的贴边投影（§7）。

不用橙色做眉题、按钮悬停色、大面积底色或背景光斑。

## 5. 圆角、边框与阴影

| 元素 | Unify 实测 | 演示站规范 |
| :--- | :--- | :--- |
| 按钮 | 5px | `rounded-[5px]`（`.u-btn`） |
| 胶囊标签 | 400px | `rounded-full`（`.u-pill`） |
| 平铺块、照片、小标签 | 3–4px | 4px（`.u-tile`）；首屏氛围面板 4px |
| 卡片 | 8px（数字卡）；定价卡约 4px | 8px（`.u-card`） |
| 产品窗口 | 18px，1px `#D7D7CF`，内高光 `inset 0 1px 0 rgba(255,255,255,.86)` + 外圈 `0 0 0 1px rgba(0,0,0,.03)` + 大而软的投影 | `AppWindow` 与代码窗口 18px，同样的边框与内高光 |
| 页脚纸面 | 10px | 10px |
| 纸面压氛围带的收边 | 底角 20px | 28px（`rounded-b-[28px]` / `rounded-t-[28px]`） |

- 卡片阴影只到 `0 2px 5px`；悬停不上浮、不加深投影（Unify 的卡片没有悬停位移）。
- 不用 2px 粗边框；边框一律 1px（可用 `box-shadow: inset 0 0 0 1px` 实现，避免影响尺寸）。

## 6. 公告条与导航

- **公告条**：炭黑底，40–42px 高，14–16px 字，单行；手机用短文案保持一行；在文档流里，随页面滚走。
- **导航条**：64px 高，**实色画布底**（不半透明、不模糊），吸顶；滚动后底边出现一条发丝线。
- **结构**：品牌在左 → 链接紧跟品牌**左对齐**（15–16px / 500，悬停时下划线从左向右展开 `.u-link`）→ 右侧「文字链 · 竖线 · 次按钮 · 主按钮」。
- **手机**：品牌 + 主按钮 + 菜单按钮。
- 导航不放支撑能力的入口（例如离线样例下载），也不给按钮加装饰性圆点。

## 7. 首屏

- 左对齐：眉题 → 衬线大标题 → 导语与入口按钮 → 一块全宽的氛围面板，面板上放对话输入框。
- **标题光晕的真实做法**：关键词文字**仍是炭黑**，只加一道贴边投影 `text-shadow: 1px 0 2px rgba(254,60,1,.65)`（`.u-aura`）。不把关键词改成橙色，不在背后铺 `blur-xl` 的橙色光斑，页面背景也不加径向光晕。
- 输入框：画布底、8px 圆角、发丝外圈与较深的投影；占位文字 16px；发送按钮为圆形炭黑按钮（Unify 在底边有一道橙色描边，我们沿用这一细节）；模型来源与推荐说法放在输入框里面。
- 首屏不重复放产品界面：紧接着的演示舞台就是产品。

## 8. 产品界面的呈现

- 产品界面以**真实窗口**出现：标题栏（窗口按钮、标题、必要时时钟）、侧栏、内容面板、状态栏。
- 窗口外部可以有一层氛围：Unify 把窗口错位叠在一块动态模糊照片上，或把界面片段放在深色模糊照片上。我们的 B 端舞台整段放在深色氛围带上；C 端舞台留在纸面上。
- 窗口内部是产品界面（D10 已定，即产品 App 的外观），不受本规范约束：按 [SHOWCASE §4.1「视窗界面规范」](../../docs/SHOWCASE-web-design.md#41-共用外壳与应用视窗)（产品界面令牌、`stage/ui.tsx`）排版，不在窗口里使用本节的大字号。

## 9. 分区过渡

- 纸面分区与全出血氛围带交替；纸面以大圆角收边、压在氛围带上：上一段 `relative z-10 rounded-b-[28px]`，氛围带 `-mt-7` 从圆角下面伸出来，下一段纸面再用 `-mt-7 rounded-t-[28px]` 盖回去。
- 氛围带（`globals.css`）：
  - `.atmo-day` 白昼暖调——首屏输入框背后；
  - `.atmo-dusk` 黄昏——B 端舞台整段背景，文字反白；
  - `.atmo-night` 夜色——页脚上方的收尾行动区。
  每种由一层大模糊的渐变（地平线色带）与一层轻模糊的细长光痕组成，模拟动态模糊照片的质感；氛围带上的文字对比度 ≥ 4.5:1。
- 同底色的相邻分区之间不画分隔线。

## 10. 动效

- 克制：选项卡 / 章节自动推进时只有进度条在动（桌面竖条在文字左侧留白里，手机横排分段）；数字可以滚动；链接下划线展开 0.3s；按钮只变深浅 0.3s；说明文字展开 0.26–0.3s `cubic-bezier(0.2,0.8,0.2,1)`。
- **不做**：圆点脉冲、卡片悬停上浮、背景光斑呼吸、弹跳的入场。
- 换章或切换选项卡时**版面高度不变**：旧说明收起与新说明展开同时进行；手机上当前章说明占固定高度。版面一变，浏览器的滚动锚定会替访客滚动页面，看起来像整页跳了一下。
- 尊重 `prefers-reduced-motion`：演示舞台不自动播放、停在静帧，其余过渡降为瞬时。

## 11. 页脚

- 收尾行动区放在夜色氛围带上：居中的衬线大标题、一句说明、两个入口（浅色按钮 + 发丝描边按钮）。
- 页脚是一张画布纸色、10px 圆角的卡片，压在氛围带下半部：四列链接（分组名弱文字 15px / 500，链接炭黑 15px，行距宽松），左下大号「旅」字标，右下版权与 [`docs/00` §0.3](../../docs/00-overview-and-glossary.md#03-三条责任边界线tripcraft-不是清单) 的三条责任边界。

## 12. 内容与工程红线

- **不虚构用户评价**。产品在设计阶段，没有真实用户；「客户故事」位置放设计场景（PRD-03），并写明「不是用户评价」，数字标明是设计目标或演示数据。
- **不虚构代码**。展示代码时只节选仓库里真实存在的文件，并标注「节选」；不写「100% 一致」「真实代码」一类无法核验的话。
- 文案遵守 [`docs/00` §0.3](../../docs/00-overview-and-glossary.md#03-三条责任边界线tripcraft-不是清单)：匹配度为信息参考；预估价以旅行社正式报价为准；平台不是旅行社，合同与付款由旅客和旅行社直接签订；不是导航软件。离线导出、车机投递等支撑能力不写成主卖点。
- **网络字体不阻塞渲染**：不在 `<head>` 里直接放 Google Fonts 样式表（连不上时整页白屏），用 `FontLoader` 挂载后插入；系统字体先渲染。
- 演示站不引入外部图片与第三方脚本；氛围用 CSS 画。

## 13. 类名速查（`src/app/globals.css`）

| 类名 | 作用 |
| :--- | :--- |
| `.u-eyebrow` | 眉题：13px / 600 / 0.08em / 炭黑 |
| `.u-aura` | 标题关键词的贴边橙色投影 |
| `.u-btn` + `.u-btn-primary` / `.u-btn-secondary` / `.u-btn-light` | 44px 高、5px 圆角、15px / 500 的按钮；炭黑主按钮 / 纸色发丝边次按钮 / 深色底上的浅色按钮 |
| `.u-pill` | 32px 高的全圆角标签，24% 灰发丝边 |
| `.u-card` | 画布底 8px 卡片，20% 灰发丝边 + 细投影 |
| `.u-tile` | `#F8F7F3` 4px 平铺块 |
| `.u-link` | 悬停时从左向右展开的下划线 |
| `.atmo` + `.atmo-day` / `.atmo-dusk` / `.atmo-night` | 氛围带 |

旧类名（`unify-btn-*`、`unify-card`、`unify-pill-badge`、`glass*`）只剩未挂载的旧场景在用，新代码不要再用。

## 14. 驳回清单

- ❌ CTA 按钮用 `rounded-full` 或 `rounded-xl`；按钮矮于 40px 或字号小于 14px。
- ❌ 把首屏关键词改成橙色并在背后铺模糊光斑；页面背景放径向光晕。
- ❌ 眉题用橙色或带底色胶囊。
- ❌ 正文小于 15px、辅助字小于 13px；任何地方出现 10–11px 文字。
- ❌ 卡片悬停上浮、圆点脉冲等装饰性循环动画；换章时版面高度跳变。
- ❌ 导航半透明叠模糊（在深色氛围带上会看不清）；链接居中排列。
- ❌ 同底色分区之间加分隔线；用浅石灰整段铺底来分区（改用氛围带或留白）。
- ❌ 虚构的用户评价、无法核验的指标与「真实代码」声明。
- ❌ 赛博紫 / 青 / 粉渐变、3D 黏土小人、低幼插画、2px 粗黑边框、在按钮与表格里用衬线体。
