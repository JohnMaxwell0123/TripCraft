## 高德地图 API Key 与安全密钥注入方式

本路书契约遵循客户端密钥隔离与最小权限原则，代码与数据中不内嵌任何生产密钥。

在编译生成单文件 HTML 或运行时接入高德地图能力时，需通过环境变量注入密钥：

```bash
# 环境变量配置
export AMAP_KEY="<你的高德Web端Key>"
export AMAP_SECURITY="<你的高德安全密钥securityJsCode>"
```

在 DSL 配置中，高德地图凭据使用统一占位符表示：

```json
{
  "amap": {
    "key": "ENV_AMAP_KEY",
    "securityJsCode": "ENV_AMAP_SECURITY"
  }
}
```

> ⚠️ **生产部署提醒**：高德开放平台 Web 服务 Key 须在控制台绑定正式域名白名单。在本地以 `file://` 或未加白域名打开产物时，TripCraft 将自动触发离线骨架图降级保护机制，确保页面不出现白屏。
